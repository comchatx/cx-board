Reports, findings and drafts cx leaves for later go on a board beside the chat. Have cx add tabs, such as one per store.

Some things you can ask:

- Put this competitor analysis on the board.
- Add a tab called "Amazon US" to the board, and put US reports there from now on.
- Turn last week's report on the board into a table.

## Files the board opens

A file named in cx's answer opens on a tab of the board. A Word file shows its headings, text, tables and pictures in the type of cx's answers, and its links show as text. An Excel file shows each of its sheets as Excel shows its cells, under a switch of their names, with the values the file saved; its hidden sheets are left out. A Word or Excel file that is locked or damaged shows “This file can't be read.”
