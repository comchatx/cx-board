- Turn last week's report on the board into a table.

## Files the board opens

A file named in cx's answer opens on a tab of the board. A Word file shows its headings, text, tables and pictures in the type of cx's answers. An Excel file shows each of its sheets as Excel shows its cells, under a switch of their names, with the values the file saved; its hidden sheets are left out. A PDF shows its pages one under another at the tab's width; pictures stored as JBIG2 or JPEG 2000, and Japanese or Korean text in a font the file doesn't carry, don't show. Links in these files show as text and can't be pressed. A Word, Excel or PDF file that is locked or damaged shows “This file can't be read.”
