# Changelog

- Unreleased: the page's elements and how a page is written. `kit/kit.css` and `kit/kit.js` are the ready-made elements Jack signed in the board's prototype (`spikes/board/elements.html`, round 8): a card, a button in its three looks, a field empty and filled, a table, a count, a switch, a list of files, an empty line, a chart and a timeline, with the chart's bars and the timeline's rows one Tab stop each. They carry no words and load nothing; the board puts both into a page before its own code. A page takes them by `<body class="kit">`: every rule is under that class and the script touches nothing at load, so a page that does not take them is drawn as it is written. They read only the theme's custom properties, each named with what it means in `kit/theme.json`, and `data-theme` and `data-locale` on the page's root. The package ships `kit/`. The skill says how a page is written: `page.html` at a board's top is drawn in a frame under a row saying cx made it, it loads nothing from the network, it is built from the elements, and it reaches the board through `window.cxBoard`, where a draft and a send each need a press inside the page and are refused without one. The skill no longer asks cx to use the board unasked: its description names two occasions alone, the seller asking for something to be put, changed or found on the board, or another plugin's skill naming the board, and the body drops "Say in your reply that you put a file on the board" and says what a file is rather than telling cx to put one. It also says that a file on the board does not hold cx's turn while pi's question box does, and that on a shared computer cx's board is `/tenant/board/<person>/`.
- 0.3.1: The card's line and the Overview, in English and Chinese, are the words signed on 2026-11-10: "Keeps cx's reports and drafts on a board beside the chat." as npm's `description`, and 「cx 的报告和草稿放上看板，不会淹没在对话里。」 as `comchatx.about`. They said "A board beside the chat for what cx and plugins make." and 「在对话旁设一块看板，cx 和插件做出的东西都放在上面。」. `DEVELOPING.md` holds the install line, `pi install npm:@comchatx/cx-board`.
- 0.3.0: the base is the seller's directory mirrored as cards and nothing else. A Markdown file in it with a title is a card of its title and words; 已读, `todo/` and `done/` move to the to-do and question module. The board holds directories, each a tab by its name, and every Markdown file at any depth under a tab is a card; a tab of the seller's own is cx making a directory. The column opens by itself on the tab a new file landed in, and cx says in its reply where it left the file.
- 0.2.1: the README in Chinese, `README.zh-CN.md`, which the Plugins page draws as the Overview in Chinese.
- 0.2.0: the board's base alone. A file is a Markdown file with a heading as its title, read and marked read; the kinds, the answers and 交给 cx move to the to-do and question module, `@comchatx/cx-board-tasks`. The column may open by itself when a turn leaves a new file.
- 0.1.2: the skill gives the shape of cx's words in an entry — a few lines with the figures that matter, one reason and the source; what cannot be undone said once, in a line of its own — and the page's names in both languages.
